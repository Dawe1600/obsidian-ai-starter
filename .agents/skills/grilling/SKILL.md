# 🎯 Skill: Grilling (Uniwersalny Standard Doprecyzowywania Informacji)

Ta umiejętność jest **jedynym i obowiązującym standardem** zadawania pytań użytkownikowi.

Uruchamiaj ją ZAWSZE, gdy:
* Brakuje Ci informacji, parametrów lub kontekstu do wykonania zadania.
* Intencja użytkownika jest niejednoznaczna lub wielowątkowa.
* Trzeba podjąć decyzję architektoniczną, projektową lub organizacyjną.
* Użytkownik proponuje nowy projekt, temat notatki lub procedurę.

Nigdy nie zadawaj luźnych, pojedynczych pytań w nieskończoność. Zamiast tego przeprowadź zwięzły wywiad rundowy.

---

## 🧭 Żelazne Zasady Wywiadu

### 1. Badanie Faktów przed Pytaniem (Fact-Finding)
* **Zadaniem agenta jest samodzielne sprawdzenie faktów:** Przed zadaniem jakiegokolwiek pytania przeszukaj pliki sejfu, notatki, strukturę folderów lub kod.
* **Nie pytaj o to, co możesz sprawdzić sam:** Jeśli informacja istnieje w plikach sejfu, odczytaj ją w tle. Pytaj użytkownika **wyłącznie o decyzje, preferencje, brakujące dane biznesowe i priorytety**.

### 2. Rundy Pytań i Granica Wiedzy (Frontier)
* Zadawaj pytania rundami. Jedna runda to zbiór pytań, które można zadać od razu bez czekania na wyniki kolejnych etapów.
* Zwięzłość: **maksymalnie 2 do 4 pytań w jednej rundzie**.
* Każde pytanie musi zawierać przemyślaną rekomendację sformułowaną tak, by użytkownik mógł odpisać po prostu słowem *"tak"*.

### 3. Obowiązujący Format Rundy

```markdown
❓ **Q1: [Krótki tytuł pytania]**
[Zwięzły opis problemu, kontekst lub dostępne opcje]
➡️ **Rekomendacja:** [Twoja konkretna propozycja działania]

---

❓ **Q2: [Krótki tytuł pytania]**
[Zwięzły opis problemu, kontekst lub dostępne opcje]
➡️ **Rekomendacja:** [Twoja konkretna propozycja działania]
```

---

## 📋 Przebieg Procesu

1. **Identyfikacja luki w wiedzy:** Agent wykrywa brakujące założenia, potrzebę wyboru lub niejednoznaczność.
2. **Cichy research:** Agent sprawdza istniejące notatki i zasoby.
3. **Formułowanie Rundy 1:** Zadanie 2-4 pytań w powyższym formacie z rekomendacjami.
4. **Przetworzenie odpowiedzi:**
   * Jeśli użytkownik odpowiada *"tak"*: agent natychmiast przechodzi do realizacji według przedstawionych rekomendacji.
   * Jeśli użytkownik modyfikuje wybór (np. *"Q1 tak, ale w Q2 wybieram opcję B"*): agent dostosowuje plan i działa.
   * Jeśli odpowiedź otwiera nowe, zależne decyzje: agent zadaje krótką Rundę 2.
5. **Realizacja i zapis:** Po zakończeniu wywiadu agent wykonuje zadanie i zapisuje ewentualne ustalenia w odpowiednich notatkach w sejfie.
